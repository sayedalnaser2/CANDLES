This page saves your changes straight to your GitHub repository, so it needs a GitHub access token. Only you can use it, and it stays in this browser.

How do I get a token?
  1. On GitHub, open Settings, Developer settings, Personal access tokens, Fine-grained tokens, then Generate new token.
  2. Name it shop manager and pick an expiry date.
  3. Under Repository access, choose Only select repositories and pick CANDLES.
  4. Under Permissions, Repository permissions, set Contents to Read and write.
  5. Generate the token, copy it, and paste it above.

Never share this token with anyone. If it leaks, delete it on GitHub and make a new one.
